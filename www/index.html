Architecture

    
From socket to response.

    
Every connection travels the same path. One event loop watches all the sockets, so a slow client never holds up a fast one.

    

      
Poller
poll() watches every listening and client socket for readiness.

      
HttpParser
Bytes in, request out — method, path, headers and body, validated.

      
Router
Picks the server and the longest matching location block.

      
Handlers
Static files, directory listings, CGI or uploads do the actual work.

      
ResponseBuilder
Status, headers and body written back to the client socket.

    

  






  

    
What it does

    
Everything a small server should.

    
All of it driven by an nginx-style configuration file.

    

      
GET
Static files
Correct MIME types, index files, and path-traversal protection built in.

      
/dir/
Autoindex
Generated directory listings with sizes and dates, switched on per location.

      
.py .sh
CGI
Scripts run through the interpreter you map to each extension, with the standard CGI environment.

      
POST
Uploads
Raw and multipart/form-data bodies saved to a configured store, with filename sanitising.

      
404
Custom error pages
Nine status codes each get their own page, and a built-in fallback if the file is missing.

      
301
Limits & redirects
Body size limits, allowed methods per route, and return redirects.

Configuration

      
One file runs the whole thing.

      
Ports, roots, error pages, CGI interpreters and upload folders are all declared, not hard-coded.

      
    
        
  • Multiple ports — several listen lines per server
    • 
        
  • Per-route methods — allowed_methods GET POST
    • 
        
  • CGI by extension — map .py and .sh to interpreters
    • 
        
  • Body limits — client_max_body_size 6M
    • 
      

    

    

      
webserver.conf


server {
    listen 8081;
    listen 8082;
    client_max_body_size 6M;

    location / {
        autoindex on;
        allowed_methods GET POST DELETE;
    }

    location /uploads {
        upload_enable on;
        upload_store ./www/uploads;
        allowed_methods GET POST;
    }

    location /cgi-bin {
        cgi_extension .py /usr/bin/python3;
        cgi_extension .sh /bin/bash;
    }

    location /old-page {
        return 301 /index.html;
    }
}
